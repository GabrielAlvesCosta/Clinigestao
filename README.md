 Clinigestão

Sistema web desenvolvido para auxiliar no **gerenciamento de informações e atendimentos de uma clínica**, permitindo organizar pacientes, consultas e prontuários em um único ambiente.

 Sobre o projeto

O **Clinigestão** foi desenvolvido com o objetivo de facilitar a rotina de uma clínica, centralizando informações importantes e permitindo um melhor acompanhamento dos atendimentos.

O sistema possui diferentes funcionalidades para cadastro, consulta e gerenciamento das informações dos pacientes.

 Funcionalidades

 Pacientes

* Cadastro de novos pacientes;
* Visualização de pacientes cadastrados;
* Edição de dados cadastrais;
* Consulta das informações dos pacientes.

Consultas

* Agendamento de novas consultas;
* Seleção de paciente, data e horário;
* Visualização das consultas agendadas;
* Consulta das consultas concluídas;
* Acompanhamento do status dos atendimentos.

 Prontuários

* Acesso aos prontuários dos pacientes;
* Visualização do histórico de prontuários;
* Abertura de prontuário de atendimento;
* Registro de informações relacionadas ao atendimento;
* Consulta do histórico do paciente.

 Auditoria

* Visualização de registros de acesso e ações realizadas;
* Acompanhamento das atividades realizadas no sistema;
* Consulta de informações relacionadas aos atendimentos.

Principais telas

O sistema possui telas para:

* Menu principal;
* Cadastro de pacientes;
* Pacientes cadastrados;
* Agendamento de consultas;
* Consultas agendadas;
* Consultas concluídas;
* Prontuários;
* Histórico de prontuários;
* Abertura de prontuário de atendimento;
* Auditoria;
* Edição de dados cadastrais.

 Segurança

Por trabalhar com informações relacionadas à saúde, o projeto considera a importância da **segurança e proteção dos dados**.

O sistema possui controle e registro das ações realizadas, contribuindo para a rastreabilidade das informações e para uma utilização mais segura dos dados.

 Objetivo

O objetivo do Clinigestão é proporcionar uma solução organizada para o gerenciamento de uma clínica, facilitando o cadastro e acompanhamento de pacientes, o agendamento de consultas e o acesso aos prontuários.

Além disso, o sistema busca contribuir para a **organização, segurança e rastreabilidade das informações**.
